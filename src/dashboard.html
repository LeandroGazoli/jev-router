How to read this page
Tier
The model class the router chose for the turn: haiku (fast), sonnet (balanced), opus (strong), fable (the opt-in long tier).
Confidence
The probability the local routing model gave to the model it chose. It is not a measure of whether the choice was right.
Low
Confidence under the router's minimum. The router never downgrades on a low answer and caps upgrades.
Overruled
Policy changed the router's pick: the risk floor, the low-confidence rules, the cache-rebuild guard, a one-step upgrade limit, or an unavailable tier.
Unavailable
The routing model could not be reached, so the current model was kept.
Manual
You picked a model yourself, so routing is paused in that session.
Idle
No new decision for 15 minutes.
Where it comes from
Sessions come from per-session files kept for 7 days. Calibration comes from the decision ledger (routing.jsonl), which stores no prompt text. Confidence bands use this process's JEV_MIN_CONFIDENCE and JEV_STEP_UP_CONFIDENCE.
